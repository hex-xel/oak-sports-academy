Review loading, error and recovery states

Loading: “Loading registrations…”; keep heading/navigation usable and mark the affected region busy. No protected-detail flash.

Empty: “No registrations yet” for an empty database; filters use “No registrations match these filters.”

Offline / timeout: “Could not load this page. Check your connection and try again.” Retry retains filters and safe form input.

Private file: loading indicator, unavailable/expired-link message, explicit retry; never show storage diagnostics.

Saving: “Saving schedule…” / “Recording decision…”; disable duplicate actions and announce progress.

Conflict: “This application has changed. Reload its details before continuing.” Never replay a stale decision.

Email failed: preserve the saved schedule/decision, show Failed and Retry email; Sent means provider acceptance, not guaranteed inbox receipt.

Accessibility: persistent labels, visible focus, text status badges, error summary linked to fields, keyboard-reachable controls; return focus after dialogs. Production needs browser keyboard/screen-reader review.
